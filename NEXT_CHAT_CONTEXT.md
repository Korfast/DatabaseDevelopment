## Что проверить дальше

1. Запустить приложение с доступной базой `VideoHostingDB`.
2. Открыть форму «Контент» и проверить отображение вкладок «Лицензии» и «Медиафайлы».
3. Проверить добавление и сохранение дочерних записей для выбранного контента.
4. Проверить три сценария ошибок: ошибка загрузки, ошибка сохранения и повторное добавление существующей связи.
5. Перед публикацией проверить состав файлов, затем сделать отдельный коммит с понятным сообщением.

## Ограничение среды

Сборка через `dotnet build` ранее останавливалась на задаче MSBuild `GenerateResource` для x86. Это ограничение среды сборки, его нужно перепроверить в Visual Studio с установленными компонентами .NET Framework 4.8.
