# DatabaseDevelopment

Учебные работы по разработке и защите баз данных. Основной проект — WinForms-приложение `VideoHostingApp` для работы с базой `VideoHostingDB`.

## Основной проект

Путь: `Основы Разработки Баз Данных/VideoHostingApp/VideoHostingApp`

Проект реализует справочники и связанные формы для контента, жанров, правообладателей, договоров, лицензий и медиафайлов. Схема DataSet хранится в `VideoHostingDBDataSet.xsd`.

Строка подключения находится в `App.config` и рассчитана на локальный SQL Server Express. Перед запуском нужно указать имя экземпляра SQL Server и убедиться, что база `VideoHostingDB` создана.

## Материалы

- `Основы Разработки Баз Данных/Lab1` — материалы первой лабораторной работы;
- `Основы Разработки Баз Данных/Lab2` — отчёт второй лабораторной работы;
- `Основы Разработки Баз Данных/Lab3` — отчёт и скриншоты третьей лабораторной работы;
- `Безопасность систем баз данных` — отдельные работы по защите баз данных.

## Сборка

Открыть `Основы Разработки Баз Данных/VideoHostingApp/VideoHostingApp.slnx` в Visual Studio с поддержкой .NET Framework 4.8 и Windows Forms. Для работы приложения требуется SQL Server с базой `VideoHostingDB`.
