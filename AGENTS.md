# Project Notes

## Project

Учебный проект по разработке базы данных: Windows Forms приложение `VideoHostingApp`.

## Working Context

- Перед началом работы прочитай `docs/context.md`.
- Прошлые итоги сессий лежат в `docs/sessions/`; читай их по необходимости.
- Подробные проверки программы ведутся в `program_verification_checklist.md`.
- Проверяй текущее состояние кода и `git status`, потому что контекст может устаревать.

## Session Finish

По запросу пользователя `Сохрани итоги сессии` или `/save_session_data`:

- Создай запись `docs/sessions/YYYY-MM-DD-NN.md`.
- Укажи задачу, сделанные изменения, причины важных решений и затронутые файлы.
- Запиши выполненные проверки и их фактические результаты.
- Отдельно укажи незавершенное, непроверенное и следующие шаги.
- Обнови `docs/context.md`: текущее состояние, открытые вопросы и ближайшие действия.
- Обнови `CHANGELOG.md`, если были изменения, заметные пользователю, преподавателю или проверяющему.
- Обнови `program_verification_checklist.md`, если выполнялась проверка программы.
- Меняй этот файл только при изменении постоянных правил или базовой информации о проекте.

## Changelog Rules

- В `CHANGELOG.md` записывай только значимые изменения проекта.
- Не дублируй туда мелкие внутренние заметки из сессий.
- Используй раздел `Unreleased` для текущих изменений до фиксации версии или сдачи этапа.
- Группируй записи по типам: `Added`, `Changed`, `Fixed`, `Removed`, `Verification`.
