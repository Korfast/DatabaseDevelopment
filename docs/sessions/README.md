# Session Notes

В этой папке хранятся краткие итоги рабочих сессий.

Рекомендуемый формат имени файла:

```text
YYYY-MM-DD-NN.md
```

Пример структуры записи:

```markdown
# Session YYYY-MM-DD-NN

## Goal

- Что нужно было сделать.

## Changes

- Что изменено.

## Decisions

- Какие решения приняты и почему.

## Verification

- Какие проверки выполнены и какой результат получен.

## Open Items

- Что осталось сделать или проверить.

## Files

- Затронутые файлы.
```
