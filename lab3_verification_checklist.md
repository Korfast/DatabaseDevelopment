- [x] Ошибки фильтрации обрабатываются локально в `RightHolderListForm` и `ContentGenresForm`; при ошибке фильтр сбрасывается.
- [x] В `Program.cs` подключён общий обработчик `Application.ThreadException` для непредвиденных ошибок пользовательского интерфейса.
- [ ] Нужно вручную проверить 2-3 ошибки для отчёта: дублирование связи `Контент_Жанр`, пустой жанр, удаление записи при наличии внешних ссылок.

Матрица ожидаемого поведения:

| Сценарий | Где возникает | Ожидаемое поведение |
|---|---|---|
| Ошибка подключения или загрузки данных | обработчик `Load` | сообщение об ошибке, форма не завершается аварийно |
| Дублирование связи `Контент_Жанр` | обработчик сохранения | сообщение об ошибке БД, введённые данные остаются в DataSet для исправления |
| Некорректное значение ComboBox | `DataGridView.DataError` | понятное сообщение об ошибке ввода |
| Ошибка выражения поиска/фильтра | `ApplyRightHolderSearch` / `ApplyFilter` | сообщение об ошибке, фильтр сбрасывается |
| Непредвиденная ошибка UI | `Program.Application_ThreadException` | общее сообщение вместо необработанного исключения |
